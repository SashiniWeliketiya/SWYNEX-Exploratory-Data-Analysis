# SWYNEX-Exploratory-Data-Analysis

This repository contains the Exploratory Data Analysis (EDA) task for the SWYNEX Technologies Internship. The analysis is performed on the **Mall Customers** dataset using Python.

---

## 📊 Project Overview
The goal of this task is to explore the customer dataset, calculate important statistics, identify underlying trends and patterns, detect anomalies, and generate useful business insights with visualizations.

---

## 🛠️ Tools & Libraries Used
* **Python**
* **Pandas** (Data manipulation & analysis)
* **Matplotlib / Seaborn** (Data visualization)

---

## 📈 Key Insights Discovered
1. **Age vs. Spending Score Relationship:** Customers under 40 exhibit significantly higher spending scores compared to older demographics.
2. **Customer Segmentation:** The relationship between Annual Income and Spending Score reveals natural clusters ideal for targeted marketing strategies.
3. **Gender Distribution:** Female customers account for **56%** (112) of the total customer base, while male customers make up **44%** (88).
4. **High-Income Outliers:** Annual income reaches up to **$137k**, representing a high-earning niche group suitable for premium services.
5. **Balanced Spending Behavior:** The average spending score hovers around **50.2**, indicating a normally distributed middle ground of moderate spenders.
